Upright Tuning Technique

  • Mute unison strings: Upright notes have 2 or 3 strings. Insert rubber wedges or a felt temper strip so only one string sounds at a time.
  • Prioritize worst notes: Use the priority list above to identify strings with greatest deviation (>10¢) to balance soundboard tension first.
  • Setting the pin: Apply firm rotational torque. Slightly loosen sharp strings first, then tune up into pitch with settling torque.
  • Shortcuts: ← / → step notes • Enter marks key as tuned • Space toggles reference tone.
